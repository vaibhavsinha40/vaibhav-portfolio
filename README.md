# Vaibhav Kumar Sinha — Portfolio

## View and edit
1. Extract the entire ZIP.
2. Open the `vaibhav-portfolio` folder in VS Code.
3. Double-click `index.html` to view it in your browser.
4. Edit, save, and refresh the browser.

No installation or build command is required. Keep the assets folder beside index.html.

| File | Purpose |
| --- | --- |
| index.html | All text, project and case-study readers, links and images |
| styles.css | Colors, fonts, layout, responsive breakpoints and hover effects |
| script.js | Menu, filters, dialogs, enlarged photos and navigation |
| assets/ | Portrait, project art, case-study graphics, travel photos and résumé |

## Editing content
Search for section titles in index.html. Each project or case has a short card and a longer dialog; edit both when changing its story. Match a card's data-open value to its dialog ID (for example phone and dialog-phone).

Replace images in assets using the same filenames, or update their paths and descriptive alt text in index.html. Replace assets/vaibhav-resume.pdf to update the downloadable résumé. The download attribute requests a download; the browser's settings determine the final save behavior.

## Content and design notes
Text and personal assets are based on supplied materials. Guesstimates use illustrative assumptions, the Uber case is hypothetical, and the McDonald's figures retain their reported-campaign attribution. The dementia prototype is not presented as clinically validated.

The reference portfolios informed general layout and interaction ideas. Their code and personal details were not reused. Reference project clicking and hover styles were inspected; this design is independently authored.

Photographs and case graphics were supplied by the user. Project covers use styled text and vector icons.
