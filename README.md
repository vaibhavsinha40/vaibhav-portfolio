# Vaibhav Kumar Sinha — Brooke-inspired portfolio

This redesign uses a pale blue background, muted purple accents, bold sans-serif typography, generous spacing, rectangular buttons, and a large rounded portrait inspired by the supplied Hostinger Brooke reference.

All original portfolio body content, photographs, resume, links, and JavaScript are preserved. Project and case filters, nine case/project readers, three enlarged travel photos, mobile navigation, keyboard dialog controls, hover effects, and reduced-motion support remain included.

## Preview
Extract the entire ZIP and open index.html in your browser. No installation or build is needed.

## Update your existing Vercel site
Replace the files in your existing GitHub portfolio repository with the extracted files. Keep index.html, styles.css, brooke.css, script.js, and assets/ together at the repository root (or your existing configured Vercel root directory). Commit the changes so the connected Vercel project can redeploy.

Make sure brooke.css is uploaded: index.html loads it after styles.css. It contains the new design. Keep your existing Vercel build and root settings for this static site.

This ZIP updates the source files; it does not itself change your live deployment.

## Files
- index.html — original content and dialogs; loads the new theme
- styles.css — original layout and interaction styles
- brooke.css — Brooke-inspired design and responsive overrides
- script.js — original menu, filters, modal and photo behavior
- assets/ — all original images and resume
